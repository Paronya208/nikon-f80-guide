# 尼康 F80 速查手册

尼康 F80 / F80D / F80S（美版 N80 / N80QD）胶片单反的中文速查手册，依据官方说明书整理修订。
单文件 HTML，离线可用，桌面与手机自适应。

**在线查看：https://Paronya208.github.io/nikon-f80-guide/**

## 内容

- 机型区别、主要规格、电池与开机、镜头兼容性
- 装胶卷、拍摄流程、P/S/A/M、对焦、测光、曝光补偿与 AE-L
- ISO 挡、自拍/连拍/多重曝光/B 门、五种闪光同步模式
- 倒卷、18 项自定义设置（粗体为出厂初始值）、提示信息速查
- 与原稿的逐条修订对照

## 使用

- 桌面端：左侧目录导航，滚动自动高亮；顶部搜索框输入关键词（按 `/` 聚焦、`Esc` 清空）。
- 手机端：目录变为横向胶囊条，卡片单列排列。
- 打印：`Ctrl+P` 自动隐藏导航。

`F80-guide.docx` 是同一内容的 Word 版，便于打印。
